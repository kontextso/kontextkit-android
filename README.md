# KontextKit (Android)

> **Internal use only.** KontextKit is **not a standalone library**. It exists so that Kontext's Android SDKs ([sdk-kotlin](https://github.com/kontextso/sdk-kotlin), sdk-react-native, sdk-flutter) can share the same underlying code instead of re-deriving it three times.

If you're building an app, install one of the Kontext SDKs instead — it will pull KontextKit in transitively.
